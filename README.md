# kiedywakacje.com

## Opis
Serwis pokazujący daty wakacji szkolnych, świąt i dni wolnych w Polsce.  
Celem projektu jest szybkie i proste sprawdzenie, ile dni zostało do najbliższego odpoczynku.

## Użytkowanie
Wejdź na [kiedywakacje.com](https://kiedywakacje.com) – daty i licznik pokażą się automatycznie.

# EN Translation

## Description
A website showing the dates of school holidays, public holidays, and days off in Poland. 
The goal of the project is to provide a quick and easy way to check how many days are left until your next time off.

## Usage
Visit [kiedywakacje.com](https://kiedywakacje.com) – the dates and countdown will appear automatically.
